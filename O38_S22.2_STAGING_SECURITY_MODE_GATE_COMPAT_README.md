# O38 S22.2 — Staging Security Mode Gate Compatibility Fix

## Purpose
Preserve the previously verified S18 contract test that treats explicit `staging` mode as a supported security surface while keeping real staging configuration fail-closed when the identity signing secret is absent.

## Contract
- `ProductionSecurityConfig.from_env({AI_OS_RUNTIME_MODE: staging})` with no secret remains **BLOCKED**.
- `UnifiedRuntimeSecurityHardeningGate.run(mode="staging")` is a synthetic contract probe and injects a non-production sentinel only when no explicit `secret_present` override is supplied.
- `run(mode="staging", secret_present=False)` remains **BLOCKED**.
- No runtime deployment or target-environment claim is made by this compatibility path.
