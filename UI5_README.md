# UI-5 O46 Decision Intelligence Surface

Upgrades the Decisions page from a backend-field registry into a business-facing decision intelligence surface.

Adds:
- leading hypothesis hero with explainable rationale and confidence
- decision story for problem, audience, promise, positioning, validation model and evidence boundary
- next-action panel with success threshold, decision rule and evidence summary
- preserves the canonical backend-derived decision surface and existing decision graph
- read-only presentation only; no approval, execution, publishing or memory mutation controls added
- responsive and RTL styling

Acceptance: targeted UI-5 suite plus compileall.
