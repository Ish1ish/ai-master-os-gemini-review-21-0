# O46-S60 — Real Provider Governed Autonomous Loop

Connects the O46 prototype to the existing real model/search providers behind S58 multi-dimensional resource governance. The loop performs two bounded cycles. Provider calls are used for research, decision synthesis, and bounded non-external execution synthesis only. No external action, automatic approval, or memory write is enabled.

Run from the workspace root with `PYTHONPATH=%CD%\src`:
- `python tests\test_o46_real_provider_loop.py`
- `python scripts\s60_real_provider_governed_autonomous_loop_gate.py`
