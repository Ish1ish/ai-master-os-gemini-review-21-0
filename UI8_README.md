# UI8-O46 — Unified Explainability Layer

Adds a product-wide, backend-derived, read-only explainability drawer to the O46 experience.

Core path:
Intent -> Research -> Decision -> Governance -> Approval -> Execution -> Outcome -> Learning -> Next Decision

Capabilities:
- Why this result?
- Evidence used
- Governance context
- What happens next
- Stage-specific explainability
- Backend-derived only / no fabricated state
- Read-only / no new approval or execution controls
- Responsive desktop/mobile behavior
- RTL-aware presentation
- Escape and overlay-close behavior
