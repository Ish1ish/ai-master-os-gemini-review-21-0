# O38 S22.3 — Staging Security Test-Contract Alignment

## Purpose
Align the historical S18 regression test with the hardened S22 staging contract.

## Why this patch exists
S22.1 changed staging from a development-like mode to a secure runtime mode: TLS and authentication are required and the identity signing secret is required for a real staging configuration. The historical S18 test still asserted that `staging` with no secret is `READY`, which conflicts with the hardened security contract.

This patch updates only that stale test expectation. It does not weaken `ProductionSecurityConfig` or the staging security boundary.

## Expected behavior
- development without a secret: READY
- staging without a real secret: BLOCKED
- staging with a secret: READY
- production without a secret: BLOCKED
- production with a secret: READY

## Acceptance
Run the targeted S18 test, the S22.1/S22.2 tests, then full regression.
