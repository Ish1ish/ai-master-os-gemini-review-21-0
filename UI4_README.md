# UI-4 O46 Evidence Explorer 2.0

Adds a backend-derived visual evidence map to the O46 experience UI.
Claims, evidence refs, conflicts and confidence are rendered from the unified experience view and exposed experiment registry.
The UI remains read-only and does not invent sources, mutate runtime state, or authorize execution.

Acceptance: targeted UI-4 test suite, UI-3 regression suite, UI-2 regression suite, UI-1 regression suite, compileall.
