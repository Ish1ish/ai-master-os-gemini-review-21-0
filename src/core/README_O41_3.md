# AI Master OS — O41.3

O41.3 hardens Egypt-first evidence quality, product/content semantics, commercial naming, and the Arabic decision surface.

## User workflow

1. Run research.
2. Read the Arabic Decision Summary.
3. Pick exactly one validation test.
4. Collect real customer evidence.
5. Add that evidence to the next research/run context.
6. Re-run and compare the recommendation.

## Language

Use `language=ar` for the human-readable Arabic decision surface and `language=en` for English output. The full JSON remains available for audit/debug.

## Important boundary

A score is a prioritization aid, not proof of demand, profitability, or product-market fit.
