# دليل تشغيل AI Master OS بالعربي

## أنت بتعمل إيه بالـ Run؟

الـ Run مش تقرير تقراه وخلاص، ومش إجابة نهائية من الإنترنت. هو حلقة قرار:

`Research → Recommendation → One Validation Test → Real-World Evidence → Re-run`

يعني النظام يطلع لك **فرضية عمل**، وأنت تستخدمها علشان تعمل اختبار صغير، وبعد ما تجمع النتيجة تدخلها في Run جديد.

## اقرأ النتيجة بهذا الترتيب

1. **التوصية** — إيه الاتجاه اللي يستحق التجربة أولًا؟
2. **ليه؟** — إيه الأدلة والدرجات اللي رفعته؟
3. **العميل** — مين المفروض عنده المشكلة؟
4. **المشكلة** — إيه الألم أو المهمة اللي بنحاول نحلها؟
5. **الـ MVP** — أقل نسخة مفيدة ممكن تختبر الوعد.
6. **الـ Validation** — إيه الاختبار اللي يثبت أو يسقط الفرضية؟
7. **حدود الدليل** — هل عندنا أدلة مصرية فعلية أم مجرد global signals؟
8. **الخطوة التالية** — نفّذ خطوة واحدة فقط، ثم اجمع الدليل.

## أعمل إيه بالبيانات؟

### مثال عملي
لو التوصية كانت خدمة بحث وتحقيق سوق:

`لا تبني SaaS.`

ابدأ بـ:

`1 target segment → 1 problem → 1 offer → 1 test`

مثال اختبار:

- اعمل عرض بسيط للخدمة.
- اختبر هل أصحاب المشاريع المهتمين بالمشكلة مستعدين لمكالمة أو Pilot مدفوع.
- سجّل عدد المهتمين الحقيقيين، عدد من أكملوا الخطوة، وعدد من وافقوا يدفعوا.
- اكتب اعتراضاتهم بلغة العملاء نفسها.
- شغّل Run جديد بالـ evidence الجديدة.

## إزاي أحلل الـ Score؟

الـ Score **ترتيب** وليس إثباتًا.

`High confidence` = الدليل أقوى داخل حدود البيانات الحالية.

`Medium` = الفرضية معقولة وتحتاج تحقق.

`Low` = إشارة ضعيفة ولا تصلح وحدها لقرار مالي.

## معنى Evidence Boundary

`local_evidence_supported`
يعني عندنا كمية كافية من الأدلة المحلية داخل التقرير لتبرير الاستنتاج في حدوده الحالية.

`global_signal_requires_local_validation`
يعني عندنا إشارة عالمية أو عامة، لكن الدليل المصري غير كافٍ. هنا **ممنوع تعتبر النتيجة طلبًا مثبتًا في مصر**.

## الـ JSON أعمل بيه إيه؟

ما تبدأش بالـ JSON.

استخدم:

**Arabic Decision Summary** = القراءة اليومية واتخاذ القرار.

**Business Report** = التقرير العملي للمراجعة والمشاركة.

**Full JSON** = التدقيق الهندسي، provenance، الـ handoffs، والـ debug فقط.

## اللغة العربية

التشغيل يدعم `language=ar` أو `language=en`.

عند اختيار العربية، يظهر **ملخص القرار بالعربية أولًا**، مع التوصية، الجمهور، المشكلة، النتيجة المطلوبة، الـ MVP، الاختبار، الدرجة، حدود الدليل، والخطوة التالية. ويمكن الرجوع للـ JSON الإنجليزي وقت التدقيق.

## أهم قاعدة

لا تنفق فلوس، ولا تبني منتجًا كبيرًا، ولا تنشر محتوى خارجي لمجرد أن الـ AI أعطى Score عالي.

الـ Run يقول لك **ماذا تختبر أولًا**. الدليل الحقيقي هو اللي يقول لك **هل تكمل ولا توقف ولا تغيّر الاتجاه**.
