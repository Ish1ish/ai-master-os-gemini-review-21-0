# O46 — Governed Autonomous Loop

O46 connects the already-verified semantic, validation, learning, governance, and execution layers into one bounded cycle. The loop is deterministic at every control boundary and remains human-governed for consequential actions.

Acceptance:
1. Durable cycle state.
2. Cycle idempotency.
3. Multi-action orchestration.
4. Human approval pause/resume.
5. O45 execution invariants preserved.
6. Unknown actions remain fail-closed.
7. Evidence can feed experiment evaluation.
8. Evaluation routes the next cycle deterministically.
9. Lifecycle events are auditable.
10. Regression + compileall + smoke + Windows wrapper.
