# كارت تشغيل سريع — AI Master OS

## بعد كل Run

1. اقرأ **الملخص بالعربية**.
2. حدّد **التوصية** و**المشكلة** و**العميل**.
3. راجع **حدود الدليل**: هل هو محلي أم global signal؟
4. اختر **اختبار تحقق واحد فقط**.
5. اجمع الدليل الحقيقي.
6. أعد التشغيل، وقارن النتيجة بالـ Run السابق.

## ما الذي لا تفعله؟

لا تبنِ SaaS، لا تنفق مبلغًا كبيرًا، ولا تنشر خارجيًا لمجرد Score مرتفع.

## اللغة

في الـ UI اختر `العربية` للحصول على Decision Surface عربية. English متاح للتدقيق والـ raw output.
