# v1.7 Adaptive Decision Intelligence Contract

v1.7 consumes v1.6 Advanced Outcome Analysis and produces a bounded advisory decision context.

Flow:

Outcome Evidence
→ v1.5 Outcome Intelligence
→ v1.6 Advanced Outcome Analysis
→ v1.7 Adaptive Decision Context
→ next decision advisory posture

Allowed effects:
- increase caution
- request refinement
- request more evidence
- identify repeated execution mismatch

Forbidden effects:
- execute an external action
- lower or bypass governance
- change authorization
- mutate O43 memory directly
- treat historical evidence as a guarantee of future outcomes

The v1.7 context is deterministic and idempotently persisted.

Decision authority remains with the existing governed decision and approval layers.
